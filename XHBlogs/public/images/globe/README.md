# Earth textures

- `earth-day.jpg`: https://unpkg.com/three-globe@2.45.6/example/img/earth-blue-marble.jpg
- `earth-night.jpg`: https://unpkg.com/three-globe@2.45.6/example/img/earth-night.jpg
- `earth-day-mobile.jpg`: 1024×512 mobile variant derived from `earth-day.jpg`
- `earth-night-mobile.jpg`: 1024×512 mobile variant derived from `earth-night.jpg`

The texture set is redistributed from the MIT-licensed `three-globe`
example assets. The source Earth imagery is NASA public-domain imagery.
