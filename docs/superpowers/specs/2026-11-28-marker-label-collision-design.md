# 足迹地球标签碰撞与优先级设计

## 目标

足迹地球的每个地点光线始终保持可见。地点标签根据屏幕上的真实重合情况决定是否显示，避免简单上下错层在多角度旋转和缩放后仍然互相遮挡。用户点击某条光线时，该地点的标签必须成为临时最高优先级，并让与它重合的其他标签淡出。

## 优先级模型

标签使用显式的 `labelPriority` 数值，不使用自动地理数据库，以便后续新增地点时直接控制：

| 地点类型 | 默认优先级 |
| --- | ---: |
| 杭州起点 | 100 |
| 国家首都 | 80 |
| 大城市 | 60 |
| 其他地点 | 40 |

当前数据映射：

- 东京：80，国家首都。
- 上海、大阪：60，大城市。
- 巴厘岛、文莱：40，其他地点。
- 杭州：100，由 `hangzhouHome` 固定提供。

数字相等时按地点在数组中的原始顺序稳定决定。用户点击某地点后，该地点在选中期间使用 `Number.MAX_SAFE_INTEGER` 作为临时优先级，高于杭州和所有普通地点。

## 数据契约

`TravelPlace` 增加可选字段 `labelPriority?: number`：

- 缺省值为 40，兼容已有和后续最简单的数据。
- 若提供，必须是有限正数。
- 无效优先级由 `validateTravelPlaces()` 拒绝。
- `TravelFallbackPlace` 不增加公开优先级字段，回退展示不需要参与地球标签碰撞。

`hangzhouHome` 保持现有坐标结构，并在标签系统中使用固定 `labelPriority: 100`。

## 屏幕空间碰撞

每个标签在每帧执行以下步骤：

1. 由标签 Sprite 的世界位置和世界尺寸计算屏幕中心、宽度和高度。
2. 使用当前相机投影到 Canvas 像素坐标。
3. 只让当前朝向相机且通过地平线可见性判断的标签参与碰撞。
4. 每个矩形保留 `4px` 的碰撞余量，避免视觉上刚接触但边界未相交。
5. 按有效优先级从高到低遍历：
   - 若标签与已保留标签均不重合，则保留。
   - 若与任一已保留标签重合，则该标签目标透明度为 0。
6. 没有重合的标签全部保留；重合只隐藏标签，不隐藏光柱、光点或点击代理。

投影和碰撞不依赖地点列表顺序；列表顺序只在优先级数值完全相同时作为稳定排序的最终决胜项。

## 交互行为

- 点击光柱、光点或标签都会选中对应地点。
- 选中地点在下一帧获得临时最高优先级。
- 与选中标签重合的其他标签平滑淡出。
- 关闭地点详情或点击地球空白区域后，选中置顶取消，恢复普通优先级规则。
- 光柱的透明点击代理保持 `MARKER_HIT_RADIUS = 0.018`，不随视觉宽度缩小。
- 地平线淡出继续优先于碰撞淡出；地点完全转到地球背面时，整个标记按现有逻辑消失。

## 动画

碰撞可见性使用独立的目标透明度和指数平滑，不修改光柱透明度：

- 标签需要隐藏时在约 `180ms` 内平滑淡出。
- 恢复显示时立即设为完全可见，避免标签在重新出现时显得迟滞。
- 光柱和光点始终保持现有透明度与发光效果。

## 组件边界

- `lib/travel.ts` 保留地点数据、验证、优先级与标签几何辅助计算。
- 新增纯函数负责矩形重合和优先级可见性求解，便于独立测试。
- `TravelGlobe.tsx` 负责相机投影、每帧收集标签矩形、应用求解结果和更新 Sprite 透明度。
- `data/travel.ts` 只维护每个地点的 `labelPriority`，不包含碰撞算法。

## 错误与退化处理

- `labelPriority` 缺失时使用 40。
- 无效优先级在数据验证阶段直接报错。
- 投影结果不是有限数时，该标签不参与碰撞并保持现有地平线逻辑。
- 标签数量较多时，每帧只做小规模两两矩形比较；当前地点规模下开销可忽略。

## 测试

必须增加以下自动化测试：

1. 无重合时所有标签保持可见。
2. 杭州与任何普通地点重合时保留杭州。
3. 首都标签与大城市标签重合时保留首都。
4. 同国家普通地点重合时保留较大的 `labelPriority`。
5. 用户点击低优先级地点后，该地点标签覆盖杭州并显示，重合的其他标签隐藏。
6. 取消选中后恢复普通优先级结果。
7. 相同优先级按稳定顺序决胜。
8. `labelPriority` 缺省为 40，非法值被数据验证拒绝。
9. 地平线不可见的标签不参与碰撞。

视觉与交互验收：

- 桌面端旋转并缩放到日本区域，确认光线始终存在，重合标签按优先级切换。
- 点击东京、大阪和上海光线，确认选中标签置顶且其他重合标签平滑淡出。
- 移动端确认光线点击代理可用，标签不溢出地球容器。

## 验收标准

- 标签只在真实屏幕矩形重合时隐藏。
- 普通状态下优先级严格满足 `杭州 > 首都 > 大城市 > 其他地点`。
- 点击地点后该地点临时高于所有其他标签。
- 光柱、光点和点击区域不因标签隐藏而消失。
- 全量测试、TypeScript、生产构建和真实浏览器验证全部通过。
