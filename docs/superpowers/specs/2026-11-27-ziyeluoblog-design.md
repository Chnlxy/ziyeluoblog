# 梓叶落の幻想郷 第一版设计

## 1. 项目目标

基于开源项目 `heiehiehi/XinghuisamaBlogs` 改造一个用于自己与朋友浏览的个人博客，第一版以主要内容展示为先，保留参考站的整体格局、毛玻璃卡片和左侧个人名片式首页，同时建立可替换的个人品牌与响应式背景系统。

第一版完成后，用户应能：

- 在本地启动网站并浏览首页、文章、归档、照片墙、说说、友链和关于页面。
- 在手机端看到竖版背景，在桌面端看到横版背景。
- 通过修改集中配置或替换图片文件更新站点名称、简介、配色和背景。
- 通过 Markdown 添加文章和说说。
- 在手机和桌面尺寸下正常操作导航、搜索和内容列表。

## 4. 技术架构

### 4.1 基线

- 上游仓库：`https://github.com/heiehiehi/XinghuisamaBlogs`
- 基线分支：`main`
- 前端目录：`XHBlogs`
- 前端框架：Next.js 16、React 19
- 样式：Tailwind CSS 4
- 内容：本地 Markdown 与 TypeScript 数据文件
- 包管理器：使用当前环境已有的 `pnpm`，生成 `pnpm-lock.yaml`

本地控制台 `my-blog-manager` 随上游源码保留，但第一版网站开发与验证不依赖它启动。后续启用在线编辑和多内容管理时再配置 Python 控制台。

### 4.2 项目位置

项目使用独立目录：

```text
C:\Users\ABANDON\Documents\ChatGPT\cpp\ziyeluoblog
```

该项目使用独立 Git 仓库，不修改同级的 C++ 项目。上游代码和许可文件保留来源说明。

### 4.3 数据流

```text
posts/*.md ─────────────┐
moments/*.md ───────────┼─> Next.js 服务端读取 ─> 页面组件 ─> 浏览器
data/*.ts ──────────────┤
siteConfig.ts ──────────┘

public/images/backgrounds/*.webp
        └─> ResponsiveBackground ─> 手机/桌面背景
```

- Markdown 文件是文章和说说的内容源。
- `data/friends.ts`、`data/albums.ts` 保存结构化占位数据。
- `siteConfig.ts` 保存品牌、简介、配色、社交链接等全站信息。
- 背景图使用本地静态资源，不依赖第三方图床。

## 5. 页面与交互设计

### 5.1 视觉系统

从两张背景图中提取的共同色系：

- 暖银杏：`#D6C160`
- 橄榄金：`#98733B`
- 雾绿：`#8D9A83`
- 暮灰蓝：`#5E706D`
- 深墨色：`#2C2A23`
- 米白色：`#FAF3DF`

站点使用深墨色遮罩和暖金色强调色，避免继续使用参考站的紫粉渐变。中文标题使用宋体风格，正文使用清晰的现代无衬线字体。

视觉识别元素：

- 轻微漂浮的银杏叶
- 柔和的暖色光晕
- 半透明磨砂玻璃卡片
- 细噪点和低对比度网格纹理

动效只服务于氛围和反馈，并遵循 `prefers-reduced-motion`。手机端降低粒子数量，保证滚动和输入体验。

### 5.2 响应式背景

新增独立背景组件：

- 手机端使用竖图，`object-position: 68% center`，突出右侧人物与画面主体。
- 768px 及以上使用横图，`object-position: center center`。
- 背景固定覆盖视口，不参与页面滚动布局。
- 图片后叠加深墨渐变遮罩，保证文字和卡片对比度。
- 背景资源缺失时自动退化为暖色渐变，不出现空白页。

背景图转换为 WebP，目标单张不超过 600 KiB。原图保留在用户桌面，项目内保存优化后的版本。

### 5.3 首页

首页沿用参考站的卡片式信息密度：

1. 顶部导航与搜索框。
2. 个人名片：头像、昵称、简介、文章/说说/照片统计和联系方式。
3. “最近状态”卡片替代第一版的音乐播放器。
4. 最新文章轮播。
5. 照片墙预览。
6. 最新说说。
7. 友链入口和页脚。

第一版移除首页的每日选刊、歌词栏和浮动音乐控件，避免加载未配置服务。

### 5.4 内容页

- 文章列表显示标题、摘要、日期、标签和封面。
- 文章详情使用 Markdown 渲染，支持标题目录、代码块和基础表格。
- 归档按年份和月份展示文章。
- 照片墙使用响应式拼贴布局和简单的图片预览。
- 说说按时间倒序展示。
- 友链为空时显示“等待交换友链”的占位卡片。
- 关于页显示作者介绍和站点说明。

## 6. 占位内容

为避免展示上游作者的私人信息，第一版替换以下内容：

- 三篇示例文章。
- 五条示例说说。
- 一个带 `梓` 字样的 SVG 头像占位。
- 一段“关于我”的说明。
- 空友链或示例友链。
- 使用用户背景和本地生成的抽象封面作为照片与文章封面。

所有占位内容都使用清楚、自然的示例文字，不使用 `TODO` 或空白页面。

## 7. 配置与可维护性

集中配置新增：

```ts
backgroundConfig: {
  mobile: "/images/backgrounds/mobile.webp",
  desktop: "/images/backgrounds/desktop.webp",
  mobilePosition: "68% center",
  desktopPosition: "center center",
}
```

更换背景时只需替换两个图片文件，或修改以上路径。颜色使用 `themeColors` 和 CSS 变量，后续上传新照片时，如果色调变化，只需调整一组颜色值。

导航配置改为第一版启用页面：

```ts
[
  { name: "首页", href: "/" },
  { name: "归档", href: "/timeline" },
  { name: "照片墙", href: "/photowall" },
  { name: "说说", href: "/moments" },
  { name: "友链", href: "/friends" },
  { name: "关于", href: "/about" },
]
```

## 8. 错误处理

- 背景图加载失败时保留 CSS 渐变。
- 内容目录为空时显示友好空状态，不渲染 `undefined`。
- 缺失头像或封面时使用本地 SVG 占位资源。
- 外部社交链接为空时不显示无效链接。
- Markdown 渲染继续使用上游的净化配置，不放开危险 HTML。
- 日期无效时回退显示原始日期文本，不导致页面崩溃。

- 手机视口约 `390 × 844`：竖版背景可见，卡片单列排列，导航可打开，无横向滚动。

- 七个启用页面均能打开。
- 文章详情能正确渲染 Markdown。

- 键盘可以访问导航、卡片链接和主题切换。

- 背景人物和关键画面不被导航、卡片完全遮挡。
